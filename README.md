# Пасека — интернет-магазин продуктов пчеловодства

## Стек

- **PHP 8.2**
- **MySQL 8** (через PDO)
- **HTML / CSS / JavaScript** (vanilla, без фреймворков)
- **localStorage** для корзины на клиенте

## Структура

paseka/
├── app/ # серверная логика (недоступна из браузера)
│ ├── config.php # подключение к БД
│ ├── .env # переменные окружения (НЕ в гит)
│ ├── includes/ # шапка, подвал
│ ├── api/ # обработчики API
│ └── sql/schema.sql # схема БД + начальные данные
│
└── public_html/ # корень сайта (доступен из браузера)
├── index.php
├── catalog.php
├── cart.php
├── about.php
├── api/ # тонкие прослойки → app/api/
├── css/
├── js/
└── img/

## Локальный запуск

1. Скопируй `app/.env.example` в `app/.env` и заполни данные.
2. Создай БД в MySQL и импортируй `app/sql/schema.sql`.
3. Настрой веб-сервер так, чтобы `public_html/` был корнем сайта.
4. Открой сайт в браузере.
